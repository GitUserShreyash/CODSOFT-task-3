# 🧑‍🎓 Student Management System (Java + Swing)

A simple desktop-based **Student Management System** built using Java Swing.  
It allows users to **add**, **remove**, and **view students**, and persists data in a text file (`students.txt`) for future use.

---

## 📌 Features

- GUI-based interface using **Java Swing**
- Add, remove, and display student records
- Data stored persistently in a **text file**
- Auto-loads saved students on application start
- Clean and beginner-friendly code

---

## 🛠️ Tech Stack

- **Language**: Java
- **GUI**: Java Swing
- **File Handling**: Plain Text File (`students.txt`)

## 🧠 How It Works  
### 👨‍💻 Classes Overview  
- **Student**: Holds student details *(name, roll number, grade, email)*  
- **StudentManagementSystem**: Handles logic for storing/removing/loading students  
- **StudentManagementApp**: Builds the GUI and handles user interactions  

## 💾 Data Persistence  
- All students are saved to a file: **students.txt**  
- On startup, the file is read and students are loaded  
- **File format**: comma-separated values
